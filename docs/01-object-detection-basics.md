# 01 · 目标检测基础

目标检测（Object Detection）要同时回答两件事：

1. **在哪里** —— 物体的位置（通常用矩形框 Bounding Box）
2. **是什么** —— 物体的类别（Class）以及置信度（Confidence）

和「图像分类」相比：分类只说整张图属于哪一类；检测要找出多个物体并各自定位。

---

## 1. Bounding Box（边界框）

常见表示：

| 格式 | 含义 | 常见场景 |
|------|------|----------|
| `xyxy` | 左上角 (x1,y1) + 右下角 (x2,y2) | 可视化、评估 |
| `xywh` | 中心 (x,y) + 宽高 (w,h) | 部分框架内部 |
| YOLO 归一化 | 中心与宽高相对整图宽高，范围 0~1 | 标注文件 `.txt` |

YOLO 标注一行示例：

```text
0 0.5 0.5 0.2 0.3
```

含义：类别 id=`0`，框中心在图像中心，宽为图宽的 20%，高为图高的 30%。

---

## 2. IoU（交并比）

衡量两个框重叠程度：

\[
\mathrm{IoU} = \frac{\mathrm{Area}(A \cap B)}{\mathrm{Area}(A \cup B)}
\]

- IoU = 1：完全重合  
- IoU = 0：无重叠  
- 评估时常用阈值 0.5（或 0.5:0.95 多档）判断「预测框是否命中」

---

## 3. NMS（非极大值抑制）

同一物体可能产生多个重叠预测框。NMS 的思路：

1. 按置信度排序  
2. 保留最高分的框  
3. 去掉与它 IoU 过高的其他框  
4. 重复直到结束  

推理时常见参数：

- `conf`：置信度阈值（低于则丢弃）
- `iou`：NMS 的 IoU 阈值（越大保留框越多）

---

## 4. 评价指标（入门版）

| 指标 | 直觉 |
|------|------|
| Precision（精确率） | 预测为正的里有多少是对的 |
| Recall（召回率） | 真实物体里有多少被找出来 |
| AP | 某类别在不同召回下的精确率曲线面积 |
| mAP | 各类别 AP 的平均 |

COCO 风格常看：

- **mAP50**：IoU=0.5 时的 mAP（较宽松）
- **mAP50-95**：IoU 从 0.5 到 0.95 的平均（更严格，业界常用）

训练日志里看到的 `mAP50`、`mAP50-95` 就是在说这些。

---

## 5. 两阶段 vs 单阶段（概念）

| 类型 | 代表 | 特点 |
|------|------|------|
| 两阶段 | Faster R-CNN | 先提候选区域再分类回归，精度常高、速度偏慢 |
| 单阶段 | YOLO、SSD | 一次前向直接出框和类别，速度快，适合实时 |

本项目主攻 **YOLO（单阶段）**。
